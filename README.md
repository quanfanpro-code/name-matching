# 📛 名称归一（name-matching）

> 一句话：账上同一家公司写法五花八门？这个技能帮你把它们统一成一个规范名字，并留下一张“谁并成了谁、凭什么”的对照表。✅

---

## 🎯 这是什么

做过账、做过台账的人都见过这种事：同一家供应商，在账上可能写作——

- “上海语荻　光电有限公司”（多了个空格）
- “YF0001_成都精睿恒光电科技有限公司”（带着系统编码前缀）
- “入库（河北雄安星煜电子科技有限公司”（摘要里抠名字带出来的杂质）
- “成都博立叶光学仪器有限公司”（把“傅”打成了“博”）

肉眼一看就知道是同一家，可一旦有几千行，人就看不过来了。**名称归一技能**就是干这件事的：机器先把能自动定的全定了，剩下真拿不准的才来问你，最后给你一份干干净净的结果表和一张可追溯的对照表。

## 🧰 什么时候用

- 📒 整合完序时账、明细账，客户 / 供应商 / 存货列里一堆重复写法；
- 🗂️ 几个系统导出的名单汇在一起，名称口径不统一；
- 📋 任何表格里有一列“名字”，需要去重归并。

## 🗣️ 怎么用

对帮你干活的智能体说一句人话就行，比如：

> “把这份表格里供应商那一列的名字归一一下。”

智能体会自动走下面的流程，全程不需要你写任何指令代码。

## ⚙️ 里面是怎么运作的（白话版）

**第 1 步：机器大扫除。** 🧹
把空格、全角半角、编码前缀（YF0001_ 这种）、摘要残渣（“入库（”“冲销”这种）全部洗掉。洗完长得一模一样的名字直接归成一组，完全不打扰你。

**第 2 步：机器自己能定的都自己定了。** 🤖
有两种情况机器敢拍胸脯自动合并：
1. 只差一个公司后缀（有限公司、股份有限公司、个体工商户这些字眼）；
2. 一个是另一个的简称（比如“上海语荻光电有限公司”就是“上海语荻光电科技有限公司”的简称），而且开头两个字一样——开头不一样的坚决不自动并，防止把“天津满运”和“宿迁满运”这种两家真公司错当成一家。

**第 3 步：像的名字配成对，机器先找证据。** 🔍
比如“博立叶”和“傅立叶”这种疑似打错字的，机器先翻账里的证据：
- 两个名字的摘要里出现过**同一张发票号**？那就是铁证，合！
- 有**同一天、同一金额、一收一付**的对应？也基本能定，合！

注意：同一张凭证里同时出现两个名字**不算证据**（付款链条上本来就可能有两家公司），机器不会拿这个说事。

**第 4 步：账里定不了的，机器自己去查工商登记。** 🏢
不是问你，是机器自己去查！因为你看到“博立叶 / 傅立叶”也定不了，最后还不是得去查工商。机器查两个问题：
- 这家公司登记的**真实全名**是什么？（账上写错了就按真名归一）
- 这两个名字**到底是不是同一家**？（工商库里两家都真实存在就分开，只有一家就合并）

**第 5 步：连工商都查不清的，才来问你。** 🙋
比如个体工商户查不到登记资料、或者查询结果自相矛盾，这种极少数才会列成一张清单请你拍板，一次看完、一次回复，不会一个问题问你八遍。要是清单超过 50 对，机器会先停下来提醒你“数据是不是有问题”，不会拿垃圾问题轰炸你。

**第 6 步：出结果。** 📦
给你一份新文件，里面是原表加一列“规范名称”，外加一张“归一对照”工作表，谁并成了谁、依据是什么、涉及多少行，一笔一笔都能倒查回去。

## 📄 你会拿到什么

1. **结果表**（新文件）：原表格 + “规范名称”列，拿去继续做账、做统计都行；
2. **归一对照**（在新文件里）：规范名称、原始称谓、涉及行数、归一依据，四样俱全；
3. **存疑清单**（在对照表末尾）：没合并的候选对和原因，留给你复核。

## 🔒 三条安全承诺

1. **永远不动你的原文件。** 结果一律另存为新文件，原文件保持只读。🛡️
2. **只动名字，不动钱。** 金额、科目、凭证号，一个字都不碰。💰
3. **拿不准绝不硬并。** 两个名字哪怕长得再像，机器定不了就放存疑清单等你拍板，宁可漏合、不可错合。⚖️

## ❓ 常见问题

**Q：名字要是并错了怎么办？** 🤔
打开新文件里的“归一对照”表，每一条都有依据记录。把不对的改回来就行，原文件一直在，随时可以重来。

**Q：每次用都要查工商吗？** 🏢
不用。账上证据（同一张发票号、同日同额收付）能定的就不查；只有真定不了的才查，而且是机器自己查，不麻烦你。查工商用的是**本技能自带**的查询功能，直接连注协的公开查询库，不用另装别的技能。它借的是你浏览器里已经登录好的状态，程序本身不碰你的账号密码；第一次使用前，在浏览器里登录一次注协知识库就行。

**Q：那什么时候才会来问我？** 🙋
只有机器连工商都查不清的时候——比如个体户没有登记资料、查询结果打架。这种很少，而且一次列清单一次问完。

**Q：两个名字像，但确实是两家公司怎么办？** 🏭
没事，机器本来就不敢随便并。你拍板“不合”之后，它们会留在存疑清单里、各自保持原名，谁也不并谁。

**Q：员工名字也要归一吗？** 👤
默认不动员工人名（“肖琴”和“肖琴”本来就是一个人，不需要归一）。唯一处理的是“何丽”和“何丽（个人）”这种写法差异，按同一个人统一写法。

**Q：查不出对象的行怎么办？** ❓
统一填占位名称（比如“未列明供应商”），保证统计口径一致，不会留下一堆空白。

**Q：这个技能认什么样的表格？** 📊
常见的表格文件都行（Excel 工作簿、逗号分隔的文本表）。名字在哪一列、叫什么列名，用的时候说一句就行，机器不猜列。

2. 🐛 **实测揪出一个真漏洞**：单个名字的清洗结果（比如把“入库（某某公司”洗成“某某公司”）不会写进规范名称列。已按“先写失败测试、再修程序”的规矩修复，并补了专门的测试用例看住它。
3. 📘 **说明书补强**：新增“失败处理”对照表（文件打不开、列名找不到、查询失败等 7 种情况各自怎么办），并在“请人拍板”处加上醒目的强制停止标记，防止智能体自作主张。
4. ✅ **独立评审过关**：改前改后两版交给独立裁判盲比，一致判定改后更好，优化才予以保留；改前版本留有备份可追溯。
