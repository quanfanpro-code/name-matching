# 改为自包含的工商查询（取代 0001 号决策）

2026-10-20 用户决定：把工商查询取数代码搬进本技能，`工商查询.py` 自带"搜索→详情→股东"最短链路，不再调用 `related-party-identification`。0001 号决策（不内置、按需引用）就此废止。

原因：用户希望技能拿到手就能直接联网查，不用先装另一个技能；批量导出、文件上传等重功能归一用不上，只搬单家查询即可。

代价与边界：仍需 Edge + OpenCLI 扩展 + 注协账号登录（登录态由浏览器自带，程序不保存凭据）；代码改编自 nigo/nigo-skills（MIT）与 jackwener/OpenCLI（Apache-2.0），来源与许可记录在 NOTICE。
