# 不内置工商查询，按需引用相关方技能的取数能力

本技能只做名称归一，不自带任何联网查询代码。合并判定默认只用账内证据（凭证摘要、发票号、同日收付等）；仅当账内证据不足以判定、且确认确实需要时，才按需调用 `related-party-identification` 技能的取数能力获取工商基本信息（法人、信用代码、股东）作佐证。

原因：取数代码重复维护成本高，两个技能各养一份会漂移；且工商查询有登录、限速等外部条件，做成默认动作会拖慢每一次归一。"工商查询不是默认动作"为用户明确要求（2026-10-20）。

已考虑的替代：内置查询（重复维护，弃）；完全不管工商（丢掉最有力的外部佐证，弃）。
